# 스마트사회적처방 성과공유회 - 참가확인증 발급 웹

2026년 9월 10일(목) 개최된 「스마트사회적처방 성과공유회」 참석자가
성명·휴대폰번호만 입력하면 참가확인증(A4)을 스스로 발급받을 수 있는 웹페이지입니다.

무료 도구만 사용합니다: **Google Sheets + Google Apps Script**.
별도의 서버, 데이터베이스, 유료 서비스가 필요하지 않습니다.

---

## 확인증이 만들어지는 방식 (꼭 읽어주세요)

확인증의 **디자인 전체 — 행사명, "참가확인증" 제목, 본문 문구, 행사 일시,
기관명, 직인, 테두리 — 는 예림님이 만드신 PNG 이미지 안에 이미 들어 있습니다.**

웹에서는 그 PNG를 배경으로 깔고, 그 위에 **딱 3가지 값만** 얹습니다.

| 순번 | 항목 | 어디서 오나요 |
|---|---|---|
| 1 | **성명** | 구글시트 `성명` 열 |
| 2 | **소속** | 구글시트 `소속` 열 |
| 3 | **발급번호** | 조회할 때 자동으로 만들어짐 (예: `SSP-20260910-001`) |

따라서 **확인증 디자인을 바꾸고 싶으시면 코드가 아니라 PNG 파일을 고쳐서
다시 올리시면 됩니다.** 글자 3개의 위치·크기만 코드에서 조정합니다.

```
├── Background.html  # (방법 B용) 배경 PNG를 글자로 바꾼 값
└── README.md        # 이 문서
```

## 동작 흐름

1. 운영자가 만족도조사 엑셀에서 **성명·소속·휴대폰번호**를 구글시트에 붙여넣습니다.
2. 참석자에게 발급 링크(비공개 URL)를 공유합니다.
3. 참석자가 링크에 접속해 성명·휴대폰번호를 입력합니다.
4. Apps Script(서버)가 시트에서 일치하는 명단을 조회합니다.
5. 일치하면 배경 PNG 위에 본인의 성명·소속·발급번호가 얹혀 화면에 나타납니다.
6. [PDF 다운로드] 또는 [인쇄]로 저장합니다. 재발급 횟수 제한은 없습니다.

## 설치 및 배포 (비개발자용 단계별 안내)

### 1단계. 구글시트 만들기

1. [Google Sheets](https://sheets.google.com)에서 새 스프레드시트를 만듭니다.
2. 이름은 자유롭게 지정합니다. (예: `성과공유회 참가확인증 명단`)

### 2단계. Apps Script 프로젝트 연결

1. 방금 만든 스프레드시트에서 `확장 프로그램(Extensions)` → `Apps Script` 클릭
   - 반드시 이 방법으로 열어야 스크립트가 해당 시트에 연결(바인딩)됩니다.
2. 기본 `Code.gs` 내용을 모두 지우고, 이 폴더의 [`Code.gs`](Code.gs)를 붙여넣습니다.
3. 왼쪽 파일 목록 `+` → `HTML` 추가 → 파일명을 정확히 **`Index`** 로 지정합니다.
   (`.html` 확장자는 자동으로 붙습니다.)
4. 이 폴더의 [`Index.html`](Index.html) 내용을 붙여넣고 저장(💾)합니다.

### 3단계. 배경 PNG 등록 ★ 새로 추가된 단계

아래 **둘 중 하나만** 하시면 됩니다.

#### 방법 A (추천) — 구글 드라이브에 PNG 올리기

1. 확인증 PNG 파일을 본인 **구글 드라이브에 업로드**합니다.
2. 그 파일을 더블클릭해서 열고, 브라우저 **주소창**을 봅니다.

   ```
   https://drive.google.com/file/d/1AbCdEfGhIjKlMnOpQrStUvWxYz012345/view
                                  └────────── 이 부분이 파일 ID ──────────┘
   ```

3. 그 ID를 복사해서 `Code.gs` 설정 [6]의 따옴표 안에 붙여넣습니다.

   ```js
   const BACKGROUND_DRIVE_FILE_ID = '1AbCdEfGhIjKlMnOpQrStUvWxYz012345';
   ```

4. 저장(💾)합니다.
   - 드라이브 **공유 설정은 바꾸지 않아도 됩니다.** 웹앱이 예림님 계정 권한으로
     직접 읽어오기 때문에, PNG가 외부에 공개되지 않습니다.
   - 한 번 읽은 이미지는 6시간 동안 기억해 두므로 페이지가 빠르게 열립니다.
   - **PNG를 새 버전으로 바꾸면** 드라이브에서 같은 파일에 `버전 관리` →
     `새 버전 업로드`를 하거나, 새로 올린 뒤 ID를 바꿔 넣으시면 됩니다.
     (최대 6시간 뒤에 반영됩니다. 바로 반영하려면 새 파일 ID로 교체하세요.)

#### 방법 B — 코드에 직접 붙여넣기

1. Apps Script 왼쪽 `+` → `HTML` → 파일명을 정확히 **`Background`** 로 지정합니다.
2. 그 파일의 내용을 **전부 지우고**, 이 폴더의 `Background.html` 안에 들어 있는
   `data:image/png;base64,....` 글자열을 통째로 붙여넣습니다.
   - ⚠️ 글자 수가 **약 27만 자**라서 붙여넣기에 시간이 좀 걸립니다.
     (그래서 방법 A를 추천드립니다.)
3. 저장(💾)합니다.

> **왜 이렇게 번거롭게 하나요?**
> PDF 저장 기능은 "다른 사이트 주소로 불러온 이미지"가 섞여 있으면 브라우저 보안상
> 저장을 거부합니다. 그래서 이미지를 주소가 아니라 **글자 형태로 바꿔서** 페이지에
> 직접 심어 넣어야 PDF가 정상적으로 만들어집니다.

### 4단계. 명단 시트 자동 생성

**방법 A (권장) — 스프레드시트 메뉴에서 실행**

1. 코드를 저장한 뒤 **스프레드시트 탭으로 돌아가 새로고침(F5)** 합니다.
2. 상단 메뉴에 **`참가확인증`** 이 새로 생깁니다.
   → `참가확인증` → `① 명단 시트 준비하기` 클릭
   - ⚠️ 이 메뉴가 보이지 않으면 스크립트가 시트에 연결되지 않은 것입니다.
     2단계를 `확장 프로그램` → `Apps Script` 경로로 다시 하세요.
3. 권한 승인 창이 뜨면 아래 방법 B의 2번 항목대로 허용합니다.

**방법 B — Apps Script 편집기에서 실행**

1. Apps Script 편집기 상단의 실행할 함수 목록에서 **`setupSheet`** 를 선택하고
   **실행(▶)** 을 누릅니다.
   - ⚠️ 이 목록은 기본값이 `onOpen`/`doGet`으로 되어 있습니다.
     **반드시 `setupSheet`로 바꾼 뒤** 실행해야 시트가 만들어집니다.
2. 최초 실행 시 권한 승인 창이 뜹니다.
   - `권한 검토` → 본인 Google 계정 선택
   - "확인되지 않은 앱" 경고가 나오면 `고급` → `(프로젝트명)(안전하지 않음)으로 이동`
     (본인이 직접 만든 스크립트이므로 안전합니다.)
   - `허용` 클릭
3. 스프레드시트로 돌아가면 **`참석자명단`** 시트가 만들어져 있습니다.

   | 성명 | 소속 | 휴대폰번호 | 발급여부 | 발급번호 | 최초 발급일시 | 발급횟수 |
   |---|---|---|---|---|---|---|

   > 이미 명단을 넣어 쓰시던 시트가 있다면, 기존 데이터는 그대로 두고
   > 빠져 있는 열(`소속` 등)만 **맨 뒤에 자동으로 덧붙습니다.**
   > 열 순서가 달라도 코드는 "열 이름"으로 찾기 때문에 정상 동작합니다.

### 5단계. 명단 붙여넣기

1. 만족도조사 엑셀에서 **성명 / 소속 / 휴대폰번호** 열을 복사합니다.
2. `참석자명단` 시트의 **A2 셀**에 붙여넣습니다.
   - 휴대폰번호는 하이픈(-) 유무 상관없습니다. 조회 시 숫자만 비교합니다.
   - `setupSheet` 실행 시 휴대폰번호 열이 텍스트 서식으로 지정되므로
     앞자리 `0`이 사라지지 않습니다.
   - 뒤쪽 발급 관리 열(발급여부/발급번호/…)은 비워두면 됩니다. 자동으로 채워집니다.
   - **소속이 없는 분**은 빈칸으로 두시면 확인증에도 소속이 비어서 나옵니다.

### 6단계. 웹 앱으로 배포

1. Apps Script 편집기 우측 상단 **`배포(Deploy)`** → **`새 배포(New deployment)`**
2. 톱니바퀴(⚙) → **`웹 앱(Web app)`** 선택
3. 배포 설정:
   - **설명**: 예) `참가확인증 발급 v1`
   - **실행 계정(Execute as)**: `나(Me)`
     → 스크립트가 관리자 권한으로 시트와 드라이브를 조회하기 위해 필수입니다.
   - **액세스 권한(Who has access)**: `모든 사용자(Anyone)`
     → 참석자가 로그인 없이 접속하기 위해 필수입니다.
4. **`배포`** 클릭 → 표시되는 **웹 앱 URL**을 복사합니다.
   - 예: `https://script.google.com/macros/s/AKfycb.../exec`
5. 이 URL을 참석자에게 문자/카카오톡 등으로 공유합니다.
   별도 로그인이 없으므로 **링크 자체를 비공개로 관리**하세요.

> ⚠️ `Code.gs` 또는 `Index.html`을 수정한 뒤에는
> `배포` → `배포 관리(Manage deployments)` → 연필(✏) → 버전을 **`새 버전`** 으로 변경 →
> `배포` 를 눌러야 수정 내용이 반영됩니다. (URL은 그대로 유지됩니다.)

### 7단계. 동작 테스트

1. `참석자명단` 시트에 본인 성명·소속·휴대폰번호를 한 줄 추가합니다.
2. 웹 앱 URL을 모바일과 PC에서 각각 열어 조회해 봅니다.
   - 하이픈 유무 두 가지 모두 정상 조회되는지 확인
3. 배경 PNG가 제대로 보이는지 확인합니다.
   - "배경 이미지가 아직 등록되지 않았습니다"가 뜨면 → **3단계**를 다시 확인
4. **성명 / 소속 / 발급번호**가 PNG의 빈칸에 정확히 들어갔는지 확인합니다.
   - 위치가 살짝 어긋나면 → 아래 "글자 위치·크기 조정하기" 참고
5. 명단에 없는 정보로 조회 시 아래 문구가 뜨는지 확인합니다.
   > 입력하신 정보를 확인할 수 없습니다. 성명과 휴대폰번호를 다시 확인해 주세요.
6. [PDF 다운로드] 버튼으로 `참가확인증_홍길동.pdf` 파일이 저장되는지,
   그리고 **A4 한 장**으로만 나오는지 확인합니다.
7. 시트에 `발급여부`, `발급번호`, `최초 발급일시`, `발급횟수`가 기록되는지 확인합니다.

## 글자 위치·크기 조정하기

PNG의 빈칸과 글자 위치가 조금 어긋난다면, `Index.html`에서
**`▼▼▼▼▼ 위치 / 글자 크기 조정 구역 ▼▼▼▼▼`** 이라고 적힌 부분만 고치시면 됩니다.
그 아래에 블록이 3개 있습니다.

```css
.cert-org  { top: 40.0%;  left: 29.6%;  font-size: 27px; ... }   /* ① 소속 */
.cert-name { top: 44.6%;  left: 29.6%;  font-size: 27px; ... }   /* ② 성명 */
.cert-no   { top: 92.5%;  left:  7.6%;  font-size: 12px; ... }   /* ③ 발급번호 */
```

> **소속과 성명은 글씨체·크기(27px)·굵기(700)·자간(0.14em)이 똑같이 맞춰져 있습니다.**
> 크기를 바꾸실 땐 ①②를 **같이** 고쳐야 짝이 맞습니다.
> (①을 고칠 땐 아래쪽 `var ORG_BASE_FONT` 값도 같은 숫자로 맞춰 주세요)

| 항목 | 의미 | 숫자를 키우면 |
|---|---|---|
| `top` | 위에서부터의 거리 (0% = 맨 위, 100% = 맨 아래) | 글자가 **아래로** 내려갑니다 |
| `left` | 왼쪽에서부터의 거리 (0% = 맨 왼쪽) | 글자가 **오른쪽으로** 갑니다 |
| `font-size` | 글자 크기 | 글자가 **커집니다** |
| `font-weight` | 굵기 (`400` 보통 / `500` 중간 / `700` 굵게 / `900` 아주 굵게) | 더 굵어집니다 |
| `letter-spacing` | 글자 사이 간격 | 글자가 더 벌어집니다 |
| `color` | 글자 색 | — |

- **1% 는 가로로 약 8px, 세로로 약 11px** 입니다. `0.5%`씩 조금씩 옮겨 보세요.
- 수정 후 반드시 **저장 → 새 버전으로 재배포 → 웹앱 새로고침** 하셔야 반영됩니다.

### 긴 소속명 처리

소속명이 길어서 자리를 넘칠 경우, 아래 순서로 **자동 처리**되므로
글자가 잘리거나 밖으로 삐져나오지 않습니다.

1. 글자 크기를 `27px` → 최소 `14px` 까지 1px씩 자동으로 줄입니다.
2. 그래도 넘치면 가로로 살짝(최대 20%) 눌러서 담습니다.

실제 동작 예시:

| 소속 | 글자 수 | 출력 크기 |
|---|---|---|
| `원주시` | 3 | 27px (성명과 동일) |
| `밥상공동체종합사회복지관` | 12 | 27px (성명과 동일) |
| `강원특별자치도 사회서비스원` | 14 | 27px (성명과 동일) |
| `강원특별자치도 사회서비스원 스마트돌봄지원단` | 23 | 19px (자동 축소) |

→ **15자 이내 기관명은 성명과 똑같은 크기로 나옵니다.**

조정하려면 `Index.html`의 아래 두 줄을 고치세요.

```js
var ORG_BASE_FONT = 27;   // 소속 기본 글자 크기 (CSS의 .cert-org font-size 와 같게)
var ORG_MIN_FONT  = 14;   // 아무리 길어도 이보다 작아지지 않음
```

> 글자가 들어갈 수 있는 **가로 폭**은 `.cert-org`의 `max-width: 58%` 로 정해집니다.
> 더 넓게 쓰고 싶으면 이 숫자를 키우세요. (단, PNG 오른쪽 여백을 침범하지 않게)

## 확인증 사양

- **용지**: A4 세로 (210mm × 297mm)
- **배경**: 예림님이 제작하신 확인증 PNG 1장 (디자인 전부 포함)
- **웹에서 얹는 값**: 성명 / 소속 / 발급번호 — 이 3가지뿐
- **서체**: Noto Sans KR (고딕 계열). 인터넷 연결이 없으면 맑은 고딕으로 대체됩니다.
- **PDF 파일명**: `참가확인증_{성명}.pdf`
- **PDF 품질**: 3~4배 해상도로 캡처(약 2382×3369px 이상)해 **A4 한 장**으로 저장됩니다.
- 확인증에 표시되는 성명·소속은 **입력값이 아니라 시트에 저장된 원본 값**을 사용합니다.
  (입력 시 띄어쓰기 차이가 있어도 확인증에는 명단 그대로 출력됩니다.)

### 📌 배경 PNG 해상도 권장사항

현재 쓰고 계신 PNG는 **794 × 1123px** 입니다.
이건 화면 기준으로는 A4 크기가 맞지만, **인쇄 기준으로는 96dpi**라서
실제 A4 용지에 뽑으면 글자·테두리가 약간 흐릿하게 나올 수 있습니다.

가능하시다면 같은 디자인을 **2480 × 3508px (300dpi)** 로 다시 내보내 주세요.
- 화면 비율이 똑같으므로 **코드는 한 글자도 고치지 않아도 됩니다.**
  파일만 바꿔 올리시면 됩니다.
- PDF 캡처 배율도 자동으로 올라가서 훨씬 선명하게 저장됩니다.

`Code.gs` 설정 [5]를 수정하세요.

## 개인정보 보호 설계

- **명단 전체가 브라우저로 전달되지 않습니다.** 성명·휴대폰번호 대조는 전부
  `Code.gs`의 `issueCertificate()` — 즉 Apps Script **서버 측**에서만 수행되고,
  조회에 성공한 **본인의 성명 / 소속 / 발급번호만** 반환됩니다.
- 조회는 `google.script.run`(내부 RPC) 방식이라 URL 파라미터에 이름·전화번호가
  노출되지 않습니다. URL을 조작해 타인의 확인증을 열람할 수 없습니다.
- 휴대폰번호는 **조회에만 쓰이고 확인증에도, 브라우저 응답에도 절대 포함되지 않습니다.**
- 발급에 사용된 성명·소속·휴대폰번호는 삭제하지 않고 시트에 계속 보관합니다.
  스프레드시트 공유 권한을 담당자 계정으로만 제한해 주세요.

## 문제 해결

| 증상 | 원인 / 해결 방법 |
|---|---|
| "배경 이미지가 아직 등록되지 않았습니다"가 뜸 | ① `BACKGROUND_DRIVE_FILE_ID`에 넣은 파일 ID가 맞는지 확인 ② 또는 `Background` HTML 파일 이름·내용 확인 ③ 저장 후 **새 버전으로 재배포**했는지 확인 |
| 배경은 나오는데 글자 위치가 어긋남 | "글자 위치·크기 조정하기" 항목 참고 (`top` / `left` 값 조정) |
| 소속이 잘려 보임 | `.cert-org`의 `max-width` 를 키우거나 `ORG_MIN_FONT` 를 낮추기 |
| `참석자명단` 시트가 안 생김 | ① 실행한 함수가 `setupSheet`가 맞는지 확인(기본값은 `onOpen`) ② 스프레드시트를 새로고침 ③ Apps Script 왼쪽 `실행 기록`에서 오류 메시지 확인 |
| 스프레드시트에 `참가확인증` 메뉴가 안 보임 | 스크립트가 시트에 연결되지 않은 상태. 시트에서 `확장 프로그램` → `Apps Script`로 다시 만들어야 함 |
| "서버 설정 오류입니다 (시트 이름 확인 필요)" | 시트 탭 이름이 `참석자명단`인지 확인. 또는 `setupSheet` 실행 |
| "서버 설정 오류입니다 (컬럼명 확인 필요)" | 시트 1행이 `성명`, `휴대폰번호` 인지 확인 |
| 명단에 있는데 "확인할 수 없습니다"가 뜸 | 휴대폰번호 앞자리 `0`이 사라졌는지 확인 (해당 열 서식을 "일반 텍스트"로 지정 후 다시 붙여넣기) |
| 소속이 비어서 나옴 | 시트 1행에 `소속` 열이 있는지, 해당 행에 값이 들어 있는지 확인 |
| 웹 앱 접속 시 권한 오류 | 배포 설정의 액세스 권한이 `모든 사용자`인지 확인 |
| 코드를 수정했는데 반영이 안 됨 | 배포 관리에서 **새 버전**으로 재배포했는지 확인 |
| PNG를 바꿨는데 반영이 안 됨 | 이미지를 6시간 캐시합니다. 즉시 반영하려면 드라이브에 **새 파일로 올려 ID를 교체**하세요 |
| PDF 버튼이 동작하지 않음 | 인터넷 연결 확인 (PDF 라이브러리를 CDN에서 불러옵니다). 대안으로 [인쇄] → "PDF로 저장" 사용 |
| PDF가 하얗게 나옴 | 배경을 드라이브 "링크 주소"로 직접 넣지 않았는지 확인. 반드시 파일 ID 또는 base64 방식이어야 합니다 |
| 인쇄 시 여백이 생기거나 잘림 | 브라우저 인쇄 설정에서 용지를 `A4`, 여백을 `없음`, 배율을 `100%`로 지정 |
| 인쇄물이 흐릿함 | 배경 PNG를 300dpi(2480×3508px)로 다시 내보내기 |
