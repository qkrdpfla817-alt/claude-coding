# 스마트사회적처방 성과공유회 - 참가확인증 발급 웹 (Node.js)

관리자가 미리 등록해둔 참가자 명단(성함/휴대폰번호)을 기준으로,
참가자가 웹에서 성함/휴대폰번호를 입력하면 참가확인증을 발급(화면 확인 · PDF 저장 · 인쇄)해주는
Node.js + Express 기반 웹 애플리케이션입니다.

> 만족도조사는 구글 폼/시트로 별도 수집하고, 그 응답자 명단을 관리자 페이지에
> **복사해서 붙여넣기(일괄 등록)** 하는 방식으로 사용하면 됩니다.

---

## 폴더 구조

```
ssp-certificate-node/
├── server.js              # Express 서버 (조회 API + 관리자 API)
├── package.json
├── .env.example           # 환경변수 예시 (복사해서 .env로 사용)
├── data/
│   ├── participants.json  # 참가자 명단 + 발급 정보 (자동 생성, git 미포함)
│   └── counter.json       # 발급번호 채번용 카운터 (자동 생성, git 미포함)
└── public/
    ├── index.html          # 참가자 화면 (조회 → 확인증)
    ├── admin.html          # 관리자 화면 (로그인 → 명단 관리)
    ├── css/style.css       # 공통 디자인 (네이비/오렌지)
    ├── css/admin.css       # 관리자 화면 전용 스타일
    └── js/main.js          # 참가자 화면 로직
    └── js/admin.js         # 관리자 화면 로직
```

## 1. 로컬 실행 방법

```bash
cd ssp-certificate-node
npm install
copy .env.example .env      # (Windows) 또는 cp .env.example .env
```

`.env` 파일을 열어 아래 두 값을 반드시 변경합니다.

```
ADMIN_PASSWORD=원하는_관리자_비밀번호
JWT_SECRET=임의의_긴_랜덤_문자열
```

서버 실행:

```bash
npm start
```

- 참가자 화면: http://localhost:3000
- 관리자 화면: http://localhost:3000/admin

## 2. 참가자 명단 등록 (관리자)

1. `/admin` 접속 후 `.env`에 설정한 비밀번호로 로그인
2. **개별 등록**: 성함/휴대폰번호 입력 후 "등록"
3. **일괄 등록**: 구글 시트(만족도조사 응답)에서 이름/전화번호 두 열을 복사해
   아래처럼 한 줄에 "이름,전화번호" 형식으로 붙여넣고 "일괄 등록"
   ```
   홍길동,01012345678
   김철수,010-2345-6789
   ```
   - 구글 시트에서 두 열을 드래그해 복사하면 탭(Tab)으로 구분되는데, 이 형식도 자동 인식됩니다.
   - 전화번호는 하이픈 유무 상관없이 자동으로 숫자만 비교합니다.
   - 이미 등록된 성함+전화번호 조합은 자동으로 건너뜁니다(중복 방지).
4. 명단 목록에서 발급 상태(발급완료/미발급), 발급번호, 등록일시 확인 및 삭제 가능

---

## 3. 참가자 이용 흐름

1. 문자로 전달받은 웹 링크(`https://your-domain.com/`) 접속
2. 성함, 휴대폰번호 입력 후 "참가확인증 조회"
3. 관리자 명단과 일치하면 참가확인증이 화면에 표시됨
   - [PDF 저장] : 확인증을 PDF 파일로 다운로드
   - [인쇄] : 브라우저 인쇄 기능으로 바로 인쇄 (버튼/입력창은 인쇄되지 않음)
   - [다시 조회] : 조회 화면으로 돌아가기
4. 일치하지 않으면 다음 문구가 표시됨:
   > 참가확인증 발급 대상자를 확인할 수 없습니다.
   > 성함과 휴대폰번호를 다시 확인해주세요.

**발급번호는 최초 조회 시 1회 생성되어 서버에 저장되며, 이후 동일인이 다시 조회해도
항상 같은 발급번호가 표시됩니다.**

---

## 4. 개인정보 보호 설계

- 참가자 명단(이름·전화번호) 전체는 브라우저로 절대 전달되지 않습니다.
  `/api/verify`는 요청자가 보낸 이름+전화번호와 서버에 저장된 값이
  정확히 일치할 때만 **본인 결과 1건**만 응답합니다.
- 관리자 API(`/api/admin/*`)는 로그인 후 발급되는 토큰(JWT, 12시간 만료)이
  있어야 호출 가능합니다.
- 조회(`/api/verify`)와 로그인(`/api/admin/login`)에는 요청 빈도 제한(rate limit)이
  적용되어 있어, 전화번호를 무작위로 대입하는 시도를 어렵게 합니다.
- 명단 데이터 파일(`data/participants.json`)과 `.env`는 `.gitignore`에 포함되어
  실수로 저장소에 커밋되지 않도록 되어 있습니다.

**운영 시 반드시 지켜야 할 사항**
- 배포 환경에서 **HTTPS**를 적용하세요 (Render, Railway 등은 기본 제공).
- `data/participants.json` 파일은 정기적으로 백업하고, 행사 종료 후
  더 이상 필요 없어지면 안전하게 삭제하세요.
- 관리자 비밀번호는 추측하기 어려운 값으로 설정하고 타인과 공유하지 마세요.

## 5. 배포 (예시: Render / Railway 등 Node 호스팅)

1. 이 폴더를 GitHub 저장소로 올립니다 (`.env`, `data/participants.json`은 자동 제외됨).
2. 호스팅 서비스에서 새 웹 서비스 생성 → 이 저장소 연결
   - Build Command: `npm install`
   - Start Command: `npm start`
3. 환경변수(Environment Variables)에 `ADMIN_PASSWORD`, `JWT_SECRET` 값을 설정
4. 배포 완료 후 발급된 URL을 문자 발송 시 참가확인증 발급 링크로 사용

> Cafe24 등 Node.js 실행을 지원하지 않는 저가형 호스팅(PHP 전용)에는
> 이 프로젝트를 그대로 올릴 수 없습니다. 그 경우 별도 PHP 버전이 필요합니다.

## 6. 행사 정보 수정하기

`server.js` 상단의 `EVENT_INFO`, `CERT_PREFIX`, `CERT_DATE_CODE` 값을 수정하면
확인증에 표시되는 행사명/일시/발급기관/발급번호 형식을 변경할 수 있습니다.
